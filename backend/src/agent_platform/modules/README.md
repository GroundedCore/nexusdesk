# 领域模块开发规划

本目录包含 13 个规划模块（12 个已有实现，新增 platform_settings 当前仅规划），每个子目录的 `README.md` 是该模块的规划入口。

- [模块总索引与协作关系](../../../../docs/architecture.md)
- [独立开发规范与统一契约](../../../../docs/module-development.md)
- [现有平台使用说明](../../../../docs/platform.md)

各模块文档分别记录当前实现、功能优先级、数据归属、接口和事件、依赖边界、设计约束、页面规划、实施阶段与验收条件。目标方法和实体不代表已实现 API 或数据库表。

新增或扩展模块时先更新契约和验收条件，再实施服务、存储、适配器及页面；交付后更新当前实现和测试证据。依赖通过组合入口注入，跨模块事务按统一规范逐步演进。

新增模块：[平台设置规划](platform_settings/README.md)，仅保留平台／租户／Agent 配置层级与继承规则、工单模式及停用流程；按本次范围采用两节结构。
