# 人工客服协同（human_handoff）

可靠切换自动与人工服务，管理接管队列、分配、交接及恢复自动服务。

本文是模块开发规划。当前实现以第 1 节和代码为准，其余内容为目标设计；P0/P1 表示建设优先级，不表示已经完成。跨模块约定见[独立开发规范](../../../../../docs/module-development.md)，全局索引见[模块架构](../../../../../docs/architecture.md)。

## 1. 当前实现与差距

已实现申请接管、领取、人工回复、恢复机器人和结束交接；新增 revision 并发校验，普通员工只能领取给自己、操作自己负责的交接。员工凭证单独生成、仅显示一次、数据库仅保存哈希，可停用；管理员仍可使用兼容的自定义主体分配。SSO、排班、技能路由、SLA 和完整人员目录约束尚未实现。

## 2. 功能模块与优先级

P0：独立开发及稳定集成所需基础能力。P1：规模化、治理或复杂场景扩展。按现有能力增量交付，不重复重建已实现功能。

| 功能模块 | 功能点 | 优先级 |
|---|---|---|
| 转接入口 | 用户请求、操作员转接、规则触发及原因分类 | P0 |
| 交接上下文 | 历史消息、当前问题、已查信息、未完成动作 | P0 |
| 接管状态 | waiting/active、接管、恢复和关闭的原子转换 | P0 |
| 自动回复隔离 | 取消 Run、拒绝迟到结果、人工消息路由 | P0 |
| 坐席身份 | 实名账号引用、队列权限与接管审计 | P0 |
| 分配策略 | 技能组、在线状态、负载、优先级与认领租约 | P1 |
| 服务时限 | 等待计时、超时提醒、升级、非工作时间处理 | P1 |
| 协作能力 | 转派、内部备注、主管协助及多人协作规则 | P1 |
| 辅助建议 | Agent 草拟回复、知识推荐，由人工确认发送 | P1 |

## 3. 数据与状态归属

现有 `handoffs`，通过唯一约束限制单会话一个活跃转接。会话 mode/assigned_to 当前在同事务更新，目标通过 conversation 状态端口。规划坐席引用、分配历史、SLA 与转派记录。

现有表由已提交的 Alembic 迁移管理；本规划不创建新表。未来扩展使用新增迁移，避免修改已应用历史迁移。跨模块数据先明确所有者，再增加服务端口。

## 4. 接口与事件契约

以下 HTTP 路径均以 `/api/v1` 为前缀。目标方法、字段和事件为待实现契约，不能作为现有 API 调用。

当前接口：`POST /conversations/{id}/handoffs`、`GET /handoffs`、`POST /handoffs/{id}/transition`，操作为 claim/resume/close。

目标契约：`request_handoff(context, conversation_id, reason)`、`claim(context, handoff_id, expected_revision)`、`transfer(...)`、`release(..., disposition)`。返回接管状态、坐席引用及会话版本；规划 handoff.requested/claimed/released 事件。

## 5. 依赖与职责边界

依赖 conversation 状态和消息、Runtime 取消端口、identity 坐席身份。队列分配由本模块管理；实际人工回复写入 conversation，业务办理仍由 customer_service 管理。

独立开发不要求立即拆成微服务。先定义 Protocol/DTO 与假实现，由组合入口注入；新增跨模块调用不直接导入对方仓储。当前共享事务例外见独立开发规范。

## 6. 关键设计约束

- 接管与自动回复提交共享会话并发控制，取消信号本身不是防迟到写入的充分条件。
- 两个坐席同时认领只能有一个成功，后者收到冲突与当前归属。
- 恢复 Agent 前明确待确认动作和未完成业务的处理，不自动重复办理。
- 交接摘要标记来源；未来模型生成摘要不能伪造已完成动作。

## 7. 管理台规划

等待与处理队列、接管、交接摘要、转派、恢复/关闭；后续增加坐席状态、SLA 提醒与建议回复。

界面权限与后端校验保持一致；配置区分草稿和生效版本。加载、空数据、冲突、拒绝和失败均有明确反馈，未实现操作不显示为可用。

## 8. 实施阶段

- P0：接入真实坐席身份和状态版本，固化接管/回复竞态规则。
- P1：技能组分配、转派、SLA、工作时间与辅助回复。

每阶段先冻结最小接口与验收用例，再实现领域服务、持久层、API 和页面；集成时验证与上下游的兼容性。

## 9. 独立开发验收

- 执行中的模型返回晚于接管时，不能写入自动回复。
- 重复转接不产生多个活跃记录，并发认领只能成功一次。
- 未获队列权限的坐席不能接管或回复其他范围会话。
- 取消端口和身份可使用假实现，数据库验证接管唯一性。

上述为目标验收条件，不是已有测试覆盖声明。已验证范围参见项目 `docs/platform-validation.md`。交付需更新本节对应测试位置及第 1 节实现状态。
