# Runtime 验证记录

日期：2026-09-20。

本文记录最初 Runtime 阶段的验证。新增平台模块及最新验证结果见 [平台验证记录](platform-validation.md)。

## 环境与结果

- Python 3.12；LangGraph 1.2.11；SQLAlchemy 2.0.54；asyncpg 0.31.0。
- 临时原生 PostgreSQL 18.4，使用独立测试库；未修改用户的正式数据库。
- Alembic `upgrade head` 在空库成功执行。
- `pytest -q`：29 passed，无跳过；包含 10 项 PostgreSQL 集成测试。
- Ruff 静态检查通过。
- 前端 TypeScript 检查与 Vite 生产构建通过。
- 存在一条 Starlette/AnyIO 的上游弃用提示，不影响测试通过。

## 已验证行为

模型 → HTTP 工具 → 观察结果 → 最终回复；独立只读工具并行；参数校验；工具超时、HTTP 错误与响应大小限制；模型超时；轮数与工具预算；重复调用检测；不同运行状态隔离。

真实 PostgreSQL 上验证了同会话并发互斥、多个 Worker 独占领取、容量限制、租户查询隔离、取消优先于成功提交、租约失效后拒绝迟到结果、排队过期、持久化历史、事件序号与重放。

通过本地真实 HTTP 服务验证了演示工具链；通过 ASGI 接口验证了创建、查询、鉴权、取消、SSE 和数据库故障的 503 响应。
