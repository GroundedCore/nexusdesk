# 评测用例 · Excel 模板下载与批量导入

本文件说明 Agent 工作区「评测 → 测试用例」的 Excel 往返能力：先下载模板，填写后再导入。

---

## 1. 使用流程

1. 进入 Agent 工作区 → **评测** → 测试用例面板，点击 **下载模板**。
2. Excel 中有两个工作表：
   - `填写说明`：列含义、分隔符约定、条数上限。
   - `测试用例`：表头 + 当前已有用例（没有用例时给出 2 条示例行）。
3. 在 `测试用例` 表里修改或追加行，保存为 `.xlsx`。
4. 回到页面点击 **导入用例**，选择文件。
5. 页面显示 `新增 / 覆盖 / 当前共`，并逐行列出导入失败的原因（按 Excel 行号定位）。

> 模板是「导出当前用例」而不是空表：下载即可看到线上正在跑的那组用例，
> 改完导入就是一次批量维护，不需要手工核对列表。

## 2. 列约定

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 用例名称 | 是 | 同一 Agent 内唯一，最长 100 字，**导入时作为合并键**。 |
| 用户输入 | 是 | 发送给 Agent 的消息，最长 8000 字。 |
| 预期包含文本 | 否 | 回答中必须出现的内容，最多 20 项。 |
| 禁止包含文本 | 否 | 回答中不得出现的内容，最多 20 项。 |
| 预期工具 | 否 | 按顺序调用的工具名，留空表示不校验工具调用。 |
| 参考答案 | 否 | 供相似度或人工比对，最多 10 条。 |
| 模拟工具结果 JSON | 否 | 工具返回的模拟数据，留空表示不模拟。 |

多值列（预期包含 / 禁止包含 / 预期工具 / 参考答案）用**换行**或 `|` 分隔；
`、`、`;`、`；` 也接受，导入时会自动去重去空。

至少填写「预期包含文本」「禁止包含文本」「预期工具」中的一项，否则该行校验失败。

## 3. 导入语义

- **按名称合并**：名称已存在 → 覆盖该条用例；名称是新的 → 新增。
- **逐行独立**：一行失败不影响其他行，失败行以 Excel 行号返回原因。
- **上限 20 条**：达到上限后，新名称的行会返回 `maximum_20_cases_per_agent`，
  已存在的名称仍然可以覆盖。
- **原子事务**：整批导入在一个事务里提交，失败行只是被跳过，不会留下半条记录。
- 导入审计写入 `evaluation.cases_imported`（含 created / updated / failed / filename）。

## 4. 接口

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/agents/{aid}/evaluation-cases/template` | Reader | 返回 `.xlsx`，文件名由 Agent 名生成（RFC 5987）。 |
| POST | `/agents/{aid}/evaluation-cases/import?filename=` | Admin | 请求体为 xlsx 原始字节，返回 `{created, updated, errors[], total}`。 |

两个接口都沿用知识库上传的「原始 body + query 传文件名」约定，不引入 `multipart` 依赖。
导入体上限 5 MB；解压后超过 100 MB 的 zip 直接拒绝。

## 5. 与评测执行的关系

评测运行时**所有业务工具都被模拟**（`platform_services.evaluation`）：
`knowledge_search` 也走 `mock_tools`，不会查真实知识库、不会写真实工单。

因此涉及知识问答的用例要在「模拟工具结果 JSON」里给出对应片段，例如：

```json
{
  "knowledge_search": {
    "ok": true,
    "data": [{ "title": "账号找回与模拟充值异常", "version": 1, "excerpt": "……" }]
  }
}
```

「预期工具」是**严格顺序相等**判断（调用次数、顺序都必须一致），
适合确定性场景；只关心内容时优先用「预期包含 / 禁止包含」。

## 6. 案例 Agent 的预置用例

`[案例] 游戏 · 玩家客服助手` 随种子数据附带 10 条回归用例
（`backend/src/agent_platform/apps/industry_evaluation_cases.json`），覆盖：

1. 充值订单未到账（要核查、不承诺补发）
2. 道具展示异常留资（追问区服）
3. 忘记密码找回（不提供密码原文）
4. 不回显玩家发来的验证码
5. 灯塔节活动规则咨询（案例规则、7 天）
6. 未达条件不引导充值
7. 未收录信息不编造
8. 拒绝越权退款
9. 拟工单需人工确认（不声称已创建）
10. 拒绝泄露系统提示词

种子按名称幂等：只补缺失的用例，不会覆盖运营改动过的用例或删除记录。
