## 1. 验收目标与组织

确认本阶段交付物**功能正确**（AC 逐条复现通过）、**业务有效**（工单闭环可见、检索质量双模式达标）、**部署承诺不破**（两容器降级形态功能完整），并给出签字结论。

| 角色 | 职责 |
|---|---|
| 产品负责人 | 验收主持；检索质量与回答引用体验判定；P2 遗留处置签字 |
| QA | AC 场景执行与记录（双模式）；回归结论；缺陷分级 |
| 研发负责人 | 环境保障（含 pgvector 与降级两套）；指标测量数据出具；缺陷修复 |
| 坐席代表 | 承诺标记入口与待跟进事项的实用性判定（UAT） |
| 运维负责人 | pgvector 镜像变更评审；替换/回退演练签字 |

## 2. 验收环境与前置条件

| 环境 | 用途 |

| 类生产环境（真实模型 + pgvector PG） | 功能验收、检索质量与性能测量 |

**前置条件**：`04-test-plan.md` 双模式矩阵用例全部通过，无 P0/P1 未关闭；验收使用专用租户与预置客户（继承 Phase 2 验收数据）。

## 3. 功能验收清单（对应 AC-1~AC-7）

| # | 验收步骤 | 通过判据 |
|---|---|---|
| A1 | 客户会话创建工单并 resolved，隔日（可改库模拟）新会话问"上次的问题处理得怎样" | Agent 引用解决结论回答（memory_search 命中或待跟进注入） |
| A2 | 坐席在工单备注勾选"标记为承诺"填写"48 小时内退款"，客户 3 天后追问 | Agent 知道承诺存在及工单当前状态；待跟进事项含该承诺 |
| A3 | 客户有在途工单时进线 | 注入含【待跟进事项】；Agent 主动提及工单进度 |
| A4 | 在无 pgvector 的 quickstart 环境重复 A1 | 关键词检索命中，回答质量可接受（人工判定） |
| A4b | 构造两条相关度相近事件（3 天前 / 150 天前） | 检索结果 3 天前的排在前面 |
| A5 | 构造超过 TTL（180 天）的事件条目，执行清理任务 | 条目 expired；检索与注入均不出现 |
| A6 | 在途工单 resolved 后再次进线 | 待跟进事项中该工单消失；解决结论可被检索到 |
| A7 | Agent 草稿移除 `memory_search` 工具并发布 | 运行时工具列表无该工具，对话不触发检索 |

每个场景执行记录：执行人、日期、环境（注明 vector/text 模式）、前置数据、实际结果、判定、截图/日志链接。A1/A4b/A6 需在两种模式下各执行一遍。

## 4. UAT 判定（坐席代表）

- 工单备注"标记为承诺"勾选入口可见、含义清晰；
- 承诺兑现后（标记或工单关闭）待跟进事项及时消失，不造成误导；
- 事件记忆内容模板（"工单 TK-008 已解决：…"）读得懂、可追溯 source_ref。

## 5. 业务指标验收

| 指标 | 目标 | 测量方法 |
|---|---|---|
| 历史工单结局正确引用率 | ≥ 80% | 评估集（≥ 15 个带历史工单结局的回头客 case）人工判分 |
| memory_search top-3 相关性 | ≥ 85%（pgvector）/ ≥ 70%（TSVECTOR） | 人工抽检 ≥ 50 次真实检索调用的 top-3 结果，双模式分别统计 |
| 事件写入延迟 | ≤ 1 分钟 | 工单状态变更时间戳 vs 记忆条目 created_at，抽 ≥ 20 例 |
| 检索性能 | P99 ≤ 300ms | 类生产压测或日志统计（单客户条目量级下） |
| TTL 任务有效性 | 过期条目不进入检索与注入 | A5 结果 + 上线后审计抽查 |

## 6. 合规核对

| # | 核对项 | 判定 |
|---|---|---|
| C1 | 检索与注入严格限定当前 tenant + customer，无跨客户泄露 | 一票否决 |
| C2 | 快速体验部署承诺：两容器、无新中间件，降级形态功能完整 | 一票否决 |
| C3 | pgvector 镜像变更可独立回滚，回退后自动降级不影响服务 | 必须通过 |
| C4 | embedding 失败不丢记忆（条目正常写入可检索、可重试） | 必须通过 |

## 7. 通过标准与签字

- **通过**：A1~A7 全部通过（A4 在降级环境单独确认）；双模式相关性各自达标；合规项全过；无 P0/P1 遗留。
- **有条件通过**：仅 P2/P3 遗留且每条有 owner 与期限，硬指标达标。
- **不通过**：任一否决项触发或硬指标未达标，修复后重验受影响项 + 回归。

输出《Phase 3 验收报告》：AC 执行记录表（含模式标注）、双模式抽检数据、镜像变更演练记录、合规核对结果、遗留清单、结论与签字（产品 / QA / 研发 / 运维）。
