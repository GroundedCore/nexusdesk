# Phase 1 · 会话摘要记忆 — 验收方案

> 状态：待实施（本阶段上线前执行）
> 创建：2026-10-10
> 依据：`01-business-goals.md`（成功指标）、`02-requirements.md`（AC-1~AC-6）；测试执行依据见 `04-test-plan.md`

## 1. 验收目标与组织

确认本阶段交付物**功能正确**（AC 逐条复现通过）、**业务有效**（长对话记忆与接管效率指标达成）、**安全可上线**（开关可回退、失败可降级），并给出签字结论。

| 角色 | 职责 |
|---|---|
| 产品负责人 | 验收主持；摘要质量与体验判定；P2 遗留处置签字 |
| QA | AC 场景执行与记录；回归结论；缺陷分级 |
| 研发负责人 | 环境保障；指标测量数据出具；缺陷修复 |
| 坐席代表 | handoff 摘要的实用性判定（UAT） |

## 2. 验收环境与前置条件

| 环境 | 用途 |
|---|---|
| 类生产环境（真实模型） | 功能验收、业务指标测量 |
| quickstart 双容器（demo 模型） | 部署承诺验证：零配置生效、零额外成本 |

**前置条件**：`04-test-plan.md` 全部用例通过，无 P0/P1 未关闭；验收使用专用租户，不与其他测试数据混用。

## 3. 功能验收清单（对应 AC-1~AC-6）

| # | 验收步骤 | 通过判据 |
|---|---|---|
| A1 | 验收租户下用 `history_turns=10` 的 Agent 进行 25 轮对话：第 1 轮声明"订单号 A123，对花生过敏"，中间填充无关问答，第 25 轮问"推荐零食" | 回复排除花生制品且能引用订单号；数据库会话行 `summary` 非空 |
| A2 | 上述会话转人工 | 坐席工作台 handoff summary 同时含"订单号 A123"与"花生过敏"，呈"摘要段 + 最近消息段"两段结构 |
| A3 | 关闭该 Agent 的 `summary_enabled`（草稿→发布）后重复 A1 | 无摘要产生，早期信息丢失（行为与旧版一致）；重新开启后恢复 |
| A4 | 将摘要模型指向故障 profile，重复长对话 | 对话全程正常回复；旧摘要保留；审计中可见失败事件；任务最终 failed，不无限重试 |
| A5 | 新会话进行 ≤10 轮对话 | `memory_tasks` 无摘要任务；`gateway_calls` 无摘要调用记录 |
| A6 | 构造超长摘要（直接改库写入长文本）后发起对话 | 注入被截断在预算内（≤800 tokens），模型调用不报错、上下文不溢出 |

每个场景执行记录：执行人、日期、环境、前置数据、实际结果、判定、截图/日志链接。

## 4. UAT 判定（坐席代表）

- 对比"仅最近 10 条拼接"与"滚动摘要 + 最近消息"两种 handoff summary，确认后者无需再向客户重复询问早期信息；
- 摘要内容无幻觉（不含有对话中未出现的事实）、无敏感信息泄露（工具调用细节、内部指令不进入摘要）。

## 5. 业务指标验收

| 指标 | 基线 | 目标 | 测量方法 |
|---|---|---|---|
| 长对话（>20 轮）早期信息引用正确率 | 信息丢失即错 | ≥ 90% | 评估集（≥ 20 个 >20 轮 case，每个含 2 个早期关键事实提问）跑批，抽样人工判分 |
| 坐席接管后重复询问率 | 高频 | 下降 ≥ 50% | 上线后 2 周人工抽检 ≥ 30 个接管会话，与上线前基线对比 |
| 单轮注入 token 成本 | 0 | ≤ 800 tokens | run trace / `gateway_calls` 抽查 ≥ 20 个注入实例 |
| 对 run 延迟影响 | 无 | 0（异步） | 对比开关开启/关闭各 20 个 run 的端到端延迟分布 |

## 6. 合规核对

| # | 核对项 | 判定 |
|---|---|---|
| C1 | 审计事件不含明文敏感信息（连接串、密钥、客户 PII 原文） | 一票否决 |
| C2 | 摘要存会话行，随会话删除而删除，无独立泄露面 | 必须通过 |
| C3 | 全局开关可即时整体关闭，回滚无需动迁移 | 必须通过 |

## 7. 通过标准与签字

- **通过**：A1~A6 全部通过；指标第 1、2 项达成（第 3、4 项为监控基线，不达标须给出处置方案）；合规项全过；无 P0/P1 遗留。
- **有条件通过**：仅 P2/P3 遗留且每条有 owner 与期限，硬指标达标。
- **不通过**：任一否决项触发或硬指标未达标，修复后重验受影响项 + 回归。

输出《Phase 1 验收报告》：AC 执行记录表、指标测量数据、合规核对结果、遗留清单、结论与签字（产品 / QA / 研发）。
