# Phase 5 · Agent 记忆配置开关 — 需求文档

## 用户故事

**US-1（实施/运营）**：我创建一个知识问答 Agent 时，希望它只用会话摘要、不沉淀客户长期记忆，不需要找研发改配置。

**US-2（高合规行业运营）**：我希望金融客服 Agent 的所有自动抽取记忆都先进入待确认队列，人工确认后才生效，而不是只看置信度阈值。

**US-3（客服主管）**：我希望控制 Agent 每轮注入的记忆条数与检索返回条数，避免注入太多噪声影响回答质量与成本。

**US-4（平台管理员）**：我希望 Agent 级配置只能收紧平台策略，任何 Agent 都不能关闭 PII 脱敏、衰退、租户隔离等合规能力。

**US-5（演示/售前）**：我希望一键把演示 Agent 的记忆全部关闭，避免演示数据污染。

## 功能需求

### FR-1 记忆配置模型

Agent 级记忆配置共 10 项，分 4 组：

| 分组 | 配置 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| 会话记忆 | `conversation_memory_enabled` | bool | true | 滚动摘要（对应既有 `summary_enabled`） |
| 长期记忆 | `customer_memory_enabled` | bool | true | 客户长期记忆总开关（对应既有 `memory_enabled`）；false 时读/写/检索全部关闭，对应选项隐藏（2026-10-18 交互修订：由置灰改为隐藏） |
| 读写控制 | `memory_read_enabled` | bool | true | 是否向上下文注入客户记忆 |
| 读写控制 | `memory_write_enabled` | bool | true | 是否允许抽取/写入长期记忆（对应既有 `memory_write`） |
| 记忆类型 | `memory_types` | list | `["profile","preference","event"]` | 允许读取/写入的长期记忆类型子集；`flag` 为治理标记，不在可选范围（受 flag 白名单平台管控） |
| 检索 | `memory_search_enabled` | bool | true | 是否注册 `memory_search` 工具 |
| 写入策略 | `memory_write_mode` | enum | `auto` | `auto`：按置信度阈值自动写入/进 pending；`review`：全部抽取记忆进待确认队列 |
| 注入上限 | `memory_inject_max_items` | int | 20 | 单次注入画像/偏好/事件条目上限（flag 独立上限不变） |
| 检索上限 | `memory_search_limit` | int | 5 | `memory_search` 返回条数上限 |
| 黑名单联动 | `memory_blacklist_auto_handoff` | bool | false | 黑名单客户进线是否自动转人工（由 Phase 4 平台配置下沉为 Agent 可收紧项，平台默认 false） |

### FR-2 配置优先级（只能收紧）

```text
全局关闭            => Agent 一定关闭（界面上该项不可开启，hover 提示"平台已禁用"）
全局开启 + Agent 关闭 => 关闭
全局开启 + Agent 开启 => 生效
```

| 规则 | 说明 |
|---|---|
| Agent 只能收紧 | 任何 Agent 配置不得使平台级关闭的能力生效；运行时按"全局 AND Agent"求值 |
| 平台级不暴露 | 01 文档"平台级能力清单"（PII/衰退/淘汰/删除合并/flag 白名单/embedding profile/租户隔离/规则扫描周期）不出现在 Agent 配置表单 |
| 数值类取下界 | `memory_inject_max_items` / `memory_search_limit` 的 Agent 值超过平台上限时按平台上限截断（生效值 = min(Agent, 平台)） |

### FR-3 配置分组与联动（表单行为）

```text
会话记忆
  [x] 滚动摘要

客户长期记忆
  [x] 启用客户长期记忆                    ← 总开关，关闭时以下全部隐藏
      [x] 读取记忆（注入到对话上下文）
      [x] 自动写入记忆
          写入策略：(•) 自动写入  ( ) 全部人工确认   ← 写开启时可见
      记忆类型：[x] 客户画像 [x] 客户偏好 [x] 事件记忆
      [x] 启用 memory_search 检索
          检索返回上限：[5]                  ← 检索开时可见
      单次注入上限：[20]
      [ ] 黑名单客户自动转人工
```

| 联动规则 | 说明 |
|---|---|
| 总开关关闭 | `customer_memory_enabled=false` 时，读/写/类型/检索/注入上限/黑名单联动全部隐藏且运行时忽略 |
| 写关读开 | 允许"只读不写"（知识库式老客户接待）；`memory_write_mode` 隐藏 |
| 读写全关 | 允许"长期记忆只建档不使用"（纯演示数据收集场景），检索自动关闭 |
| 类型为空 | `memory_types` 至少保留一项，否则禁止保存并提示 |
| 存量映射 | 旧三开关 → 新配置：`summary_enabled`→`conversation_memory_enabled`；`memory_enabled`→`customer_memory_enabled` 且 `memory_read_enabled`；`memory_write`→`memory_write_enabled`；其余取默认值 |

### FR-4 写入策略（`memory_write_mode`）

| 模式 | 行为 |
|---|---|
| `auto` | 维持 Phase 2 行为：置信度 ≥ 阈值直接 active，低于阈值进 pending |
| `review` | 全部抽取记忆（无论置信度）一律 `status='pending'` 进待确认队列，人工确认后生效；人工/规则来源不受影响 |

### FR-5 预设模板

配置页提供"应用预设"（应用后各项仍可独立修改，不锁定）：

| 预设 | 配置要点 |
|---|---|
| 普通客服 | 摘要开、读写开、检索开、auto 写入、默认上限 |
| 高合规客服 | 摘要开、读开、写开、`review` 全部待确认 |
| 知识问答 | 摘要开、客户长期记忆关（读/写/检索全关） |
| 短期问答 | 仅摘要开，长期读写与检索关闭 |
| 演示 Agent | 全部关闭 |

### FR-6 生效时机与审计

| 项 | 说明 |
|---|---|
| 生效时机 | 配置保存后**新会话**生效；进行中的会话沿用会话创建时的快照，避免上下文结构中途突变 |
| 审计 | 配置变更沿用平台 Agent 配置审计（记录操作人、变更前后值），不新增审计 action |
| 权限 | 沿用 Agent 配置权限：operator 可改，viewer 只读 |

## 非功能需求

- 配置读取在 run 热路径零额外查询：随 Agent 配置一并加载，不新增 DB 往返；
- 存量 Agent 迁移为纯数据回填，无锁表风险（单表加列 + 默认值回填）；
- 表单校验即时反馈（类型为空、上限超平台值时保存前提示）。

## 验收标准

| # | 场景 | 预期 |
|---|---|---|
| AC-1 | 打开智能体配置页 | 10 项记忆配置按 4 组展示，默认值正确，viewer 只读 |
| AC-2 | 关闭"客户长期记忆"总开关并保存 | 读/写/检索/类型/上限等后续选项隐藏；新会话注入段无客户记忆、不注册 memory_search、不触发抽取任务 |
| AC-3 | 配置"只读不写"（读开写关） | 新会话正常注入既有记忆；对话后无新记忆产生（无抽取任务） |
| AC-4 | 写入策略设为 `review` | 高置信抽取记忆同样进入待确认队列，确认前不注入 |
| AC-5 | 记忆类型仅勾选"客户画像" | 仅 profile 参与注入与抽取写入；preference/event 不注入、不写入 |
| AC-6 | 平台关闭记忆（全局开关 off），Agent 配置全开 | 运行时行为为全关；界面对应项提示"平台已禁用" |
| AC-7 | Agent 注入上限设为 999（超平台上限） | 生效值被截断为平台上限；保存时提示 |
| AC-8 | 应用"高合规客服"预设 | 各配置项按预设填入且可再修改；行为符合 review 语义 |
| AC-9 | 存量 Agent（升级前创建）升级后 | 新配置值按 FR-3 映射规则回填；升级前后同一会话注入段内容逐位一致 |
| AC-10 | 会话进行中修改 Agent 记忆配置 | 当前会话行为不变；下一会话按新配置执行 |
| AC-11 | 配置变更 | 平台审计记录操作人与变更前后值 |
