# 管理控制台统一视觉规范

本版按已确认的 UI V1 效果图，以模型网关为全站视觉基准。

## 公共入口

- `frontend/src/styles/theme.ts`：Ant Design 公共主题，包含主色、文字、控件尺寸、卡片、表格、页签、弹窗及抽屉。
- `frontend/src/styles/design-system.css`：共享 CSS 变量、页面容器、旧版原生表单和表格的兼容样式、响应式布局。
- `main.tsx` 应用主题；Agent、工具目录、开放平台沿用同一个主题对象，不再维护各自的主题数值。
- 页面根节点统一带 `module-page module-<模块名>`，业务组件的布局与权限行为保持独立。

## 视觉约定

| 项目 | 规范 |
| --- | --- |
| 主色 | `#6562ff`，CSS 使用 `--ui-accent` |
| 页面 / 侧栏 | 白底 / 浅灰底，当前导航使用浅紫底与紫色文字 |
| 边框 | `#e7e9f1`，避免厚边框和强阴影 |
| 主体宽度 | 最大 1800px；桌面两侧 40px，中屏 24px，手机 16px |
| 普通控件 | 高度 36px，圆角 6px |
| 卡片与面板 | 圆角 8px；边框分区；常规内边距 20–24px |
| 表格 | 浅灰表头、细分隔线，行操作统一用主色文字按钮 |
| 页签 | 紫色文字及细下划线，间距 26px |
| 状态 | 正常绿色、处理中紫色、待处理黄色、失败红色，始终保留文字说明 |
| 字体 | Inter / Microsoft YaHei；多语言保留既有字体回退 |

## 模块落地

- 开放平台：应用状态筛选侧栏、应用卡片、统一顶层导航；状态查询在服务端执行，列表与总数使用同一条件。
- 工具目录：工具集列表改为表格，保留 API 管理、编辑、复制、引用查看、停用、归档和删除。
- 企业身份：OIDC、企微、钉钉、飞书以选择卡显示；选择后显示相应配置字段。
- Agent、知识库、工单：公共主题覆盖控件；卡片、表格、筛选器与模型网关一致。
- 总览、会话、人工协同、通用消息、访问策略、评测和审计：保留业务布局，统一旧版原生控件、面板、状态与表格。
- Agent 编辑器保留专注模式、分栏与试聊；聊天组件保留应用自定义主题色，默认色与公共主题一致。

不使用效果图中的示例名称、数量或时间替换真实业务数据。后续新增页面应复用公共主题，避免新增模块级主色和控件圆角覆盖。
